# دليل فعاليات الشرقية

موقع عربي ثابت يعرّف بفعاليات المنطقة الشرقية: ثقافة، ترفيه، طعام، وتراث، مع فلترة للحجوزات المعروضة ونماذج تُغلق برسالة داخل المتصفح.

## 1 ما هو المشروع

`index.html` عنوانه «دليل فعاليات الشرقية». وصف الميتا: «دليلك الشامل لفعاليات المنطقة الشرقية - ثقافة، ترفيه، طعام، وتراث». الصفحات: الرئيسية، الفعاليات، من نحن، التواصل.

## 2 لماذا بُني

نص الصفحة يربط الدليل بتنشيط الترفيه والسياحة وتوثيق الموروث ضمن رؤية 2030، ويذكر إثراء وكأس العالم 2026 في الشرقية. هذه صياغة الواجهة، وليست وثيقة مستقلة خارج HTML.

## 3 من يستخدمه

| الزائر | ما يفعله في الملفات |
| --- | --- |
| عائلة أو سائح | يتصفح البطاقات ويصفّي المدينة والنوع |
| من يريد حجزاً أو رسالة | يملأ نموذجاً يرى تنبيهاً محلياً فقط |

غير موثق حسابات موظفين أو لوحة إدارة.

## 4 الميزات

- شريط تنقل: الرئيسية، الفعاليات، من نحن، التواصل معنا.
- أقسام: مقدمة، معرض اكتشاف، ثلاث خدمات (مذاق الشرقية، ترفيه ومغامرات، ثقافة وفنون)، نموذج حجز، إثراء، رؤية 2030، كأس العالم 2026.
- فلترة المدينة: الكل، الدمام، الخبر، الأحساء، الظهران.
- فلترة النوع: الكل، ثقافية، ترفيه، طعام، رياضية، تراثية.
- بطاقات فعاليات موسومة بـ `data-city` و`data-type`.
- نموذجا الحجز والتواصل يمنعان الإرسال الافتراضي ويعرضان `alert` ثم تفريغ الحقول.
- تنسيقات في `css/style.css` وحركة ظهور في `css/animations.css`.
- خط IBM Plex Sans Arabic محلي. لا مكتبات واجهة خارجية في صفحات HTML.

## 5 سير العمل

```
index.html
   |-- تصفح البطاقات
   |-- نموذج حجز -> تنبيه نجاح محلي
   v
pages/events.html -> filter.js يظهر أو يخفي البطاقات
pages/about.html
pages/contact.html -> تنبيه شكر محلي
```

## 7 رحلة المستخدم

1. يفتح `index.html` ويقرأ المقدمة.
2. ينتقل إلى «اكتشف الفعاليات» أو يملأ الحجز.
3. في صفحة الفعاليات يغيّر المدينة أو النوع فتختفي البطاقات غير المطابقة (`display: none`).
4. في التواصل يرسل الاسم والبريد والموضوع والرسالة ويرى تنبيه الشكر.

المطابقة صارمة: المدينة والنوع يجب أن يساويا قيمة `dataset`، أو تكون القيمة «الكل».

## Quick Start

افتح `index.html` في المتصفح. جرّب فلتر الدمام أو الأحساء من صفحة الفعاليات. أرسل نموذج الحجز وستظهر رسالة «تم استلام طلب حجزك بنجاح، سيتم التواصل معك قريباً.» داخل المتصفح فقط.

## For Non-Technical Users

الموقع للتصفح والتعرف على فعاليات الشرقية. رسالة نجاح الحجز أو التواصل تعني أن النموذج أُغلق على جهازك، ولا تعني أن الطلب وصل إلى مكتب.

## For Developers

أبقِ قيم `option` مطابقة لـ `data-city` و`data-type`. إذا أضفت حفظاً حقيقياً لاحقاً فالنماذج الحالية لا تملك `action` ولا طلب `fetch`.
